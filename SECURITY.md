# Security policy

Security fixes are applied to the latest version on `main` and the live app at [app.boobs.pictures](https://app.boobs.pictures).

Report vulnerabilities through GitHub's [private vulnerability reporting form](https://github.com/sanay-ourora/boobs-pictures-app/security/advisories/new). Do not disclose an unpatched vulnerability in a public issue.

Include the impact, reproduction steps, affected URLs or commits, and any suggested mitigation. Never include real user credentials or private sighting data in a report.

The current prototype is a static client. Hosting accounts, GitHub accounts, CARTO, OpenStreetMap, and future infrastructure providers remain subject to their own security programs.
